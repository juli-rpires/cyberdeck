Cyberdeck

Computador portátil construído a partir de sucata eletrônica.

Sobre o projeto

O Cyberdeck é um projeto experimental de construção de um computador portátil utilizando componentes eletrônicos reaproveitados e materiais disponíveis.

A proposta combina eletrônica, hardware, montagem física e programação, buscando demonstrar como materiais que seriam descartados podem ser transformados em um dispositivo funcional e de baixo custo.

Objetivo

Projetar e construir um computador portátil funcional a partir de componentes de sucata eletrônica.

Hardware

A versão inicial do projeto utiliza:

* Motorola Moto G54;
* Mini teclado Bluetooth com touchpad;
* Caixa ou maleta reaproveitada;
* Power bank;
* Cabos e conectores.

O smartphone funciona como núcleo do dispositivo, concentrando processamento, memória, tela e sistema operacional.

Software

O projeto utiliza o Termux para disponibilizar um ambiente Linux no smartphone.

Os ambientes gráficos considerados são:

* XFCE4;
* LXQt;
* MATE;
* KDE.

O XFCE4 é indicado no projeto como a opção com melhor equilíbrio entre desempenho e funcionalidade.

Montagem

A montagem será realizada seguindo estas etapas:

1. Seleção dos componentes;
2. Testes individuais;
3. Planejamento do espaço interno;
4. Adaptação do invólucro;
5. Fixação dos componentes;
6. Testes de funcionamento;
7. Ajustes finais;
8. Registro fotográfico do processo.

Documentação

A proposta completa do projeto está disponível no arquivo:

Projeto_Cyberdeck.pdf

Fotos, códigos, esquemas e registros da montagem serão adicionados ao repositório conforme o desenvolvimento do projeto.

Resultados esperados

Espera-se obter um dispositivo portátil capaz de realizar tarefas básicas de computação, como digitação, navegação e produtividade, utilizando materiais reaproveitados.

O projeto também busca estudar conceitos de hardware, software, reaproveitamento eletrônico e computação de baixo custo.

Possíveis evoluções

Futuramente, o Cyberdeck poderá ser desenvolvido utilizando outras plataformas, como:

* Raspberry Pi;
* Orange Pi;
* Banana Pi;
* ESP32;
* TV Box;
* Placa-mãe de computador ou notebook.
